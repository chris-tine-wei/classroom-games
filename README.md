# Classroom Games

These are three vocabulary games I built for a small online ESL class: three students aged 10 to 13, over five months. Each game is built around one chapter of the novel we read together.

**Play them:** https://chris-tine-wei.github.io/classroom-games/

| Game | Format | Chapter |
|---|---|---|
| [Quidditch Jeopardy](jeopardy/) | Team quiz with wagers, timer and podium | 11 |
| [Tomodachi Hogwarts](tomodachi-hogwarts/) | Story told in scenes, two players taking turns | 10 |
| [Remembrall Dive Race](remembrall-dive-race/) | Timed race, one shared class score | 9 |

## Why games

My students were more engaged when the lesson was a game. They got competitive over the scoreboard and started arguing about points. One student finds it hard to put his thoughts into spoken sentences, and that bit of competition got him talking. I design my data visualizations on the same principle: people understand what they're drawn into.

## How they're built

- Each game is a single HTML file with no frameworks and no external requests, so it runs offline.
- Sound effects are generated in the browser with the Web Audio API. There are no audio files.
- The teacher runs the game on a shared screen while students answer out loud.
- I designed these and directed the build with AI assistance, then refined them over months of classroom use.
